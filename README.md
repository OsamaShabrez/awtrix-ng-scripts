# Home Assistant Playground

A collection of **Home Assistant blueprints, automations, scripts, helpers, and experiments** from my personal smart-home setup.

This repository is essentially my Home Assistant playground — a place to build, test, break, improve, and share things that I find useful.

## What's inside

You'll find various Home Assistant projects and experiments, including:

* 🏠 Automation blueprints
* 🤖 Automations and scripts
* 📟 AWTRIX / Pixel Clock integrations
* 🔌 Smart-home device automations
* 🌦️ Weather-based automations
* 📱 Notification and presence automations
* 🧪 Experimental ideas and prototypes
* 🛠️ Miscellaneous Home Assistant helpers and utilities

Things may range from polished and reusable blueprints to very specific solutions created for my own setup.
